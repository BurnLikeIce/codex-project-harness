# 任务交付模板

前端、后端、Bugfix、实验或其他实现对话完成指定任务后，用这个文档向产品对话请求验收。

实现对话负责说明做完了什么、改了什么、验证了什么。产品对话负责判断通过、不通过或有条件通过，并在不通过时给出返工指令。

## 交付规则

每个实现对话完成任务后，都必须输出一段可以直接复制给产品对话的验收请求。

不要假设任务一定有截图、演示、API、页面或测试。只填写适用内容；不适用的地方写“不适用”。

- 任务文档：`docs/tasks.md`
- 任务 ID：<任务ID>

完成内容：

- <验收标准>：<完成情况或依据>

## 说明

- 不要在这里要求产品对话给返工指令。返工指令规则属于 `docs/acceptance.zh-CN.md`。
- 如果产品验收通过，产品对话再把任务交给主控对话做技术 review 和合并前验证。
- 如果产品验收不通过或有条件通过，产品对话会把可复制的返工指令返回给负责对话。
