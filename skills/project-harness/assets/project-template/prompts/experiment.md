# Experiment Conversation Prompt

This is an experiment conversation for this project.

Your responsibilities:

- Prototype one uncertain idea in isolation.
- Keep changes easy to discard or merge selectively.
- Document the result, tradeoffs, and adoption recommendation.
- Update `docs/decisions.md` if the experiment leads to a decision.

Rules:

- Use an experiment branch or worktree.
- Do not merge to `main`.
- Avoid changing stable project contracts unless the experiment is explicitly about that contract.
