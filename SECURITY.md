# Security Policy

## Supported Versions

Security fixes are applied to the latest released Project Harness version.

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting feature from the repository's Security tab. Do not publish secrets, exploit details, or sensitive project content in a public issue.

Include the affected script or workflow, operating system, reproduction steps, expected boundary, and observed impact. Project Harness scripts operate on local project files, so path validation, preservation of unmanaged content, and avoidance of unintended Git or external actions are security-sensitive behavior.
